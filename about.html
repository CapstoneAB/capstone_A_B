About Buildmart

Our project overview and delivery plan.

Project Overview

Buildmart is the Capstone A team's Secure Retail System — a front-end e-commerce experience for a hardware and home goods store. The centrepiece of the project is the Shopping Cart module: customers can browse the product catalogue, add items to a cart, adjust quantities, and check out with GST-inclusive pricing calculated live.

The project was built using a real Git workflow: GitHub Issues, feature branches, pull requests, and code review, with every teammate owning a distinct part of the module.

Project Description

The shopping cart is built with plain HTML, CSS, and JavaScript. Each core capability — displaying products, adding to cart, viewing the cart, updating quantities, calculating totals — was delivered as its own feature branch so the team's contributions are all visible in the repository's history.
